## ℹ️ About this repository 

My journey through **100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu — starting from scratch.

**Background:** linguist and teacher, transitioning to Python development with no prior coding experience.

Here I keep all the projects I build day by day — from basics like loops and functions to OOP, APIs, and games. Each file is one day of the course.

> 💡 **This is a learning log, not a portfolio.** Some solutions may be simple — that's the point.

## 📚 Concepts covered

- **Days 1–12**: basics — variables, loops, functions, lists, dictionaries, strings
- **Day 13**: debugging — tracebacks, `print` debugging, breakpoints (no project)
- **Day 14**: Higher or Lower — game logic
- **Day 15**: Coffee Machine (procedural) — nested dictionaries, resources, transactions
- **Day 16**: Coffee Machine (OOP) — classes, objects, modules
- **Day 17**: Quiz Game with API — `requests`, JSON, classes from data
- **Days 18–19**: Turtle Graphics — drawing, coordinates, `turtle` module, Turtle Race Game
- **Days 20–21**: Snake Game — OOP with inheritance, game logic, events, restart
